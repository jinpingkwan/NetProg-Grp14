Achievements

Every objective from the project proposal, delivered and working end-to-end against a live Containerlab environment.

01 Overview

The proposal (NetAuto_Project_Proposal.html) committed to a Typer CLI wrapping Ansible playbooks against a Docker/Containerlab lab, covering five device-configuration tasks, device info retrieval, and Linux system reporting. All seven of those objectives are implemented and reachable through the netauto command, plus fleet-wide discovery and a full documentation set that weren't in the original scope.

03 Beyond the proposal

  • Fleet discovery extra — netauto discover sweeps the whole inventory in one pass and reports UP/DOWN, model, OS, and version per host; not one of the original seven objectives, added as the first command run after any lab deploy.
  • Real IOS-XE, not just a simulator extra — the lab runs two actual Cisco CSR1000v VMs via vrnetlab/QEMU under Containerlab, not a stripped-down NETCONF stub, alongside two custom Alpine Linux servers.
  • Installable CLI extra — pip install -e . registers netauto as a real entry point (via pyproject.toml), routing every subcommand through ansible-runner rather than shelling out to ansible-playbook.
  • Documentation set extra — an installation guide, a full CLI→playbook reference map, and a future-improvements writeup (dynamic inventory via NetBox) beyond the proposal's planned README.

04 Try it

Discover the fleet

$ netauto discover

Configure a router (default data interface)

$ netauto configure ip router1 --ip 192.168.10.1 --mask 255.255.255.0

Configure a specific interface

$ netauto configure ip router1 --ip 192.168.20.1 --mask 255.255.255.0 --iface GigabitEthernet4

Pull Linux system info

$ netauto info system server1
